# Member Access setup

The paid access page reads all member resource links from `.env.local` so they are not exposed on the public sales page.

Required variables:

FACEBOOK_GROUP_URL=
LINE_OPENCHAT_URL=
LINE_OPENCHAT_CODE=
FINANCIAL_CHECKLIST_URL=
WEBAPP_URL=
PRIVATE_LINE_URL=
EBOOK_URL=
EBOOK_PASSWORD=

After editing `.env.local`, restart `npm run dev`.
