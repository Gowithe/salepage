# Passive Income Sale Page — Clean Scan Edition

เวอร์ชันนี้ต่อยอดจาก Offer Slider Fixed และทำความสะอาดข้อความ/UX เพิ่มเติม

- ลบข้อความภายในที่ไม่ควรให้ลูกค้าเห็น เช่น “เราเอาภาพยาวเดิมออกแล้ว…”
- ปรับหัวข้อ Offer Slider ให้เป็นภาษาสำหรับลูกค้า
- เปลี่ยนลูกศร ‹ › เป็นไอคอน SVG เพื่อไม่ให้เครื่องหมายลอยผิดตำแหน่ง
- ปรับข้อความรีวิวให้เป็นธรรมชาติขึ้น
- เปลี่ยน “Hero Feature” เป็นภาษาไทย
- ลดการซ้ำของวิดีโอ Web App ใน section ถัดไป
- ปรับ Checkout / Payment / Access ไม่ให้มีข้อความ developer เช่น V1, mock, Environment Variable หรือ token
- เพิ่มหมายเหตุว่าภาพกราฟิกใน Slider เป็นภาพสรุป และสิทธิ์จริงยึดตามข้อความ/เงื่อนไขหน้าเว็บ

รันด้วย:

```bash
npm install
npm run dev
```
